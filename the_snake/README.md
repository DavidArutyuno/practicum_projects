## Описание проекта

Классическая компьютерная игра **«Змейка»** является одной из самых известных в мире игр.<br>
**Суть игры** заключается в том, что игрок управляет змейкой, которая движется по игровому полю, разделённому на клетки.<br>
**Цель игры** — увеличивать длину змейки, «съедая» появляющиеся на экране яблоки (часто изображаемые в виде точек или других символов).<br>


## Правила игры

- Змейка состоит из сегментов.
- Змейка движется в одном из четырёх направлений — вверх, вниз, влево или вправо. Игрок управляет направлением движения, но змейка не может остановиться или двигаться назад.
- Каждый раз, когда змейка съедает яблоко, она увеличивается в длину на один сегмент.
- В данной версии игры змейка может проходить сквозь одну стену и появляться с противоположной стороны поля.
- Если змейка столкнётся сама с собой — игра начинается сначала.


## Как локально развернуть проект

1. Клонируйте [этот репозиторий](https://github.com/DavidArutyuno/the_snake) на свой компьютер

2. В директории **the_snake** разверните и активируйте виртуальное окружение:

**Команда для Windows:**

    python -m venv venv
    source venv/Scripts/activate

**Команда для Linux и macOS:**

    python3 -m venv venv
    source venv/bin/activate

3. Установите зависимости проекта:

    pip install -r requirements.txt

4. Запустите скрипт **the_snake.py**
