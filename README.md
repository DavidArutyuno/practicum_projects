## 📋 Описание проекта

QRKot - это благотворительный фонд, который собирает пожертвования для помощи кошачьей популяции. Приложение позволяет создавать целевые проекты (например, на корм, медицинское обслуживание, организацию приютов) и автоматически распределять пожертвования по проектам.

### 🎯 Основные возможности

    Создание целевых проектов с указанием цели сбора

    Приём пожертвований от пользователей

    Автоматическое распределение пожертвований по проектам

    Управление проектами (редактирование, удаление, просмотр)

    Отслеживание прогресса сбора средств для каждого проекта

    up! Добавлен механизм авторизации и разграничение прав пользователей

### 🔄 Автоматическое инвестирование

    Пожертвования автоматически распределяются в самый "старый" открытый проект

    Если пожертвование превышает требуемую сумму проекта, остаток переходит в следующий проект

    При создании нового проекта все неинвестированные пожертвования автоматически вкладываются в него

## 🚀 Быстрый старт


1. Клонирование репозитория

```bash
git clone https://github.com/DavidArutyuno/QRkot-spreadsheets.git
cd cat-charity-2
```

2. Настройка виртуального окружения

```bash

# Создание виртуального окружения
python -m venv venv

# Активация (Linux/Mac)
source venv/bin/activate

# Активация (Windows)
venv\Scripts\activate
```

3. Установка зависимостей

```bash
# Обновление pip
python -m pip install --upgrade pip

# Установка зависимостей
pip install -r requirements.txt
```

4. Настройка базы данных

```bash
# Применение миграций
alembic upgrade head
```

5. Запуск приложения

```bash
# Запуск сервера разработки
uvicorn app.main:app --reload
```

Приложение будет доступно по адресу: http://localhost:8000

## ⚙️ Бизнес-правила

### ✅ Что можно делать

    Создавать проекты с уникальными названиями

    Редактировать открытые проекты

    Удалять проекты без инвестиций

    Делать пожертвования любого размера

### ❌ Ограничения

    Нельзя редактировать закрытые проекты

    Нельзя устанавливать требуемую сумму меньше уже инвестированной

    Нельзя удалять проект, в который уже были инвестированы средства

    Имя проекта должно быть уникальным

### 🎓 Права пользователей
    
#### Анонимный пользователь

    Может просматривать полный список целевых проектов, открытых и закрытых.
    Может отправить запрос на регистрацию.

#### Зарегистрированный пользователь

    Может просматривать полный список целевых проектов, открытых и закрытых.
    Может отправлять пожертвования.
    Может просматривать полный список своих пожертвований.
    Информация о том, инвестировано пожертвование в какой-то проект или нет, обычному пользователю недоступна.

#### Суперпользователь

    Может всё то же, что и зарегистрированный, но плюс к тому:

    может создавать целевые проекты,
    может изменять название и описание существующего проекта, устанавливать для него новую требуемую сумму (но не меньше уже внесённой),
    может удалять проекты, в которые не было внесено средств,
    может просматривать список всех пожертвований, при этом ему выводятся все поля модели.

#### Пользователям с любым уровнем доступа запрещено:

    удалять пользователей,
    редактировать или удалять пожертвования,
    редактировать или удалять закрытые проекты,
    удалять проекты, в которые инвестированы средства,
    изменять даты создания и закрытия проектов.


### 🔄 Логика распределения

    Пожертвования инвестируются в самый старый открытый проект

    Если сумма превышает потребность проекта, остаток переходит в следующий

    При отсутствии открытых проектов, пожертвования ждут нового проекта

    Новые проекты сразу получают все ожидающие пожертвования

## 🛠️ Технологический стек

    FastAPI - современный веб-фреймворк

    SQLAlchemy 2.0 - ORM для работы с базой данных

    Pydantic - валидация данных и схемы

    Alembic - миграции базы данных

    SQLite - база данных (для разработки)

    Pytest - тестирование

    Uvicorn - ASGI-сервер

## 🔧 Настройки

Основные настройки находятся в app/core/config.py:

```python
class Settings(BaseSettings):
    app_title: str = 'Благотворительный фонд поддержки котиков QRKot'
    app_description: str = 'Сервис для поддержки котиков'
    database_url: str = 'sqlite+aiosqlite:///./fastapi.db'
    secret: str = 'SECRET'
```

### 📝 Примеры запросов

#### Создание проекта

```bash
curl -X POST "http://localhost:8000/charity_project/" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Корм для бездомных котиков",
    "description": "Сбор средств на покупку корма для бездомных кошек",
    "full_amount": 10000
  }'
```
#### Создание пожертвования

```bash
curl -X POST "http://localhost:8000/donation/" \
  -H "Content-Type: application/json" \
  -d '{
    "full_amount": 5000,
    "comment": "На корм для котиков"
  }'
```
