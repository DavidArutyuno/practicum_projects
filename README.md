## 🛠 Быстрый старт

Чтобы развернуть проект локально на ПК, находясь в папке foodgram, выполните команду

```bash
docker-compose up
```

При выполнении этой команды контейнеры frontend, db, backend и nginx описанные в docker-compose.yml, подготовят всю инфраструктуру, необходимую для работы web-приложения.
