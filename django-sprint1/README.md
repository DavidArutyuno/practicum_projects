## Как локально развернуть проект

1. Клонируйте [этот репозиторий](https://github.com/DavidArutyuno/django-sprint1) на свой компьютер

2. В директории **django-sprint1** разверните и активируйте виртуальное окружение, обновите pip:

**Команда для Windows:**

    python -m venv env
    source env/Scripts/activate

**Команда для Linux и macOS:**

    python3 -m venv env
    source env/bin/activate

Убедитесь, что всё установлено правильно:

    pip list

3. Установите зависимости проекта:

        pip install -r requirements.txt

4. Перейдите в директорию с файлом **manage.py** и примените миграции:

        python manage.py migrate

5. Запустите сервер разработки (виртуальное окружение должно быть активно):

        python manage.py runserver

6. Откройте [ссылку](http://127.0.0.1:8000/) в любом браузере и насладитесь успехом
